# Portable Notepad++ Visual Git Command Launcher

An automated, interactive Git command search engine and visual launcher for Notepad++ using **NppExec**, **Python (Tkinter)**, and an **XML database**. Search your personalized Git command library by tags/keywords, view live animated GIF visual diagrams of Git operations, read in-depth explanations (`<desc1>`) and practical use cases (`<desc2>`), fill in placeholders (`<commitmsg>`, `<branchname>`, `<commithash>`), and execute commands directly in the Notepad++ console.

---

## 🌟 Features

* **Visual GIF Diagrams:** Displays live animated diagrams for each Git command showing file movement (Working Directory $\rightarrow$ Staging Area $\rightarrow$ Local Repo $\rightarrow$ Remote), HEAD pointer movement, branch merging, rebase, and stashing.
* **In-Depth Guidance (`<desc1>` & `<desc2>`):** Multi-tiered documentation detailing technical mechanisms under the hood (`<desc1>`) and practical use-cases / best practices (`<desc2>`).
* **Instant Tag Search & Scoring:** Search Git commands by tags, descriptions, or keywords sorted by relevance score.
* **Interactive Command Picker:** Browse matching commands in a side-by-side GUI window using keyboard arrow keys.
* **Smart Parameter Prompts:** Automatically opens a wide modal dialog when commands contain placeholders like `<commitmsg>`, `<branchname>`, or `<commithash>`.
* **Keyboard-First Workflow:** Press `ESC` to exit without running anything, `Ctrl+Enter` or `Enter` to submit.
* **Full Portability:** Uses `$(NPP_DIRECTORY)` variables—works seamlessly across portable USB drives or different system paths.

## 📋 Prerequisites

1. **Notepad++** (Portable or Installed version).
2. **Python 3** installed on your system path (verify with `python --version` in terminal).
3. **NppExec Plugin** installed in Notepad++:
   - Open Notepad++ $\rightarrow$ Go to `Plugins` menu $\rightarrow$ `Plugins Admin...`
   - Search for **NppExec** $\rightarrow$ Check the box $\rightarrow$ Click **Install**.

## 📁 File Placement

Copy/clone all project files directly into your **Notepad++ Root Directory** (e.g. `C:\Program Files\Notepad++\` or `E:\server\0installed\notePad++\npp.8.9.portable\`):

```text
Notepad++/ (Your Notepad++ Root Directory)
├── git_commands.xml                  # XML database of Git commands & metadata
├── git_picker.py                     # Python Tkinter GUI picker & input dialogs
├── generate_visuals.py               # Auto-generator for visual GIF diagrams
├── git_picker_nppExec_command.txt    # NppExec script reference
└── visuals/                          # (Auto-created) Directory with 18 animated GIFs
```

## 🚀 Step-by-Step Setup Guide

Follow these 4 simple steps after downloading/cloning from GitHub:

### Step 1: Copy Files to Notepad++ Directory
Copy `git_commands.xml`, `git_picker.py`, and `generate_visuals.py` into your Notepad++ main folder (where `notepad++.exe` is located).

---

### Step 2: Register NppExec Script in Notepad++
1. Open **Notepad++**.
2. Press **`F6`** (or go to `Plugins` $\rightarrow$ `NppExec` $\rightarrow$ `Execute...`).
3. Copy and paste the following script into the command window:

```text
// Navigate to active working directory
cd "$(CURRENT_DIRECTORY)"

// Prompt for search keyword
inputbox "Enter keyword/tag to search Git commands:" ""

if "$(INPUT)" != "" then
    // 1. Launch Python Tkinter GUI picker
    py "$(NPP_DIRECTORY)\git_picker.py" "$(INPUT)"
    
    // 2. Load the SELECTED_CMD variable generated by Python
    npp_exec "$(NPP_DIRECTORY)\selected_cmd.txt"
    
    // 3. Multi-line formatted console execution
    if "$(SELECTED_CMD)" != "" then
        npp_console 1
        echo ========================================
        echo Executing Command:
        echo   $(SELECTED_CMD)
        echo ========================================
        cmd /c $(SELECTED_CMD)
    endif
endif
```

4. Click **Save...**, enter the name **`Git Launcher`**, and click **Save**.
5. Click **Cancel** to close the dialog.

---

### Step 3: Add Launcher to Notepad++ Menu
1. Go to `Plugins` $\rightarrow$ `NppExec` $\rightarrow$ `Advanced Options...`
2. Under **Associated script**, select **`Git Launcher`** from the dropdown.
3. In the **Item name** field, type **`Git Launcher`**.
4. Click **Add/Modify**.
5. Check the box **"Place to the Macro menu"** at the bottom left.
6. Click **OK** and **restart Notepad++**.

---

### Step 4: Assign a Global Keyboard Shortcut
1. Go to `Settings` $\rightarrow$ `Shortcut Mapper...`
2. Select the **Plugin commands** tab (or **Macro** tab).
3. Scroll down to locate **`Git Launcher`**.
4. Double-click it (or click **Modify**) and assign a key combination (e.g. `Ctrl + Alt + G` or `Alt + G`).
5. Click **OK** and close the window.

---

## 🎯 How to Use

1. Open any project file inside your Git repository folder in Notepad++.
2. Press your keyboard shortcut (e.g. `Ctrl + Alt + G`).
3. Type a search term or tag (e.g. `add`, `commit`, `stash`, `rebase`, `branch`).
4. Use **`Up` / `Down` Arrow Keys** to navigate commands:
   - View live animated GIF diagram illustrating the command mechanism.
   - Read in-depth technical explanation (`HOW IT WORKS`) and practical use cases (`USE CASES & TIPS`).
5. Press **`ENTER`** to execute:
   - If the command requires inputs (like commit message or branch name), a modal popup prompt will ask for details.
   - The command will execute directly inside Notepad++'s built-in console window!
